# Java Fundamentals

This repository contains Java programs covering core programming concepts and problem-solving exercises.

## Topics Covered

- Input and Output
- Operators
- Primitive Data Types
- Loops
- Conditional Statements
- Number Programs
- Basic Calculators

## Project Structure

```
src/
└── com/
    └── java/
        └── fundamentals/
```

## Getting Started

1. Clone the repository.
2. Open it in IntelliJ IDEA or VS Code.
3. Run any Java class with a `main` method to explore the examples.
